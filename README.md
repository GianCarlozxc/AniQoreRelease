# AniQore Releases

Android downloads for AniQore.

## Current preview: v1.12.4

[Download AniQore APK](https://github.com/GianCarlozxc/AniQoreRelease/releases/download/v1.12.4/AniQore-v1.12.4.apk) | [Release notes](https://github.com/GianCarlozxc/AniQoreRelease/releases/tag/v1.12.4)

Requires Android 8.0 or newer. This is a debug-signed preview build. App and playback testing are pending manual review.

Features include online username/password accounts, open registration, encrypted remembered sessions, account-separated local libraries, an upward-sliding Discover headline, anime discovery and search, dark/light appearance, Library and Plan to Watch, season/episode browsing, native video controls, completion tracking, resume banners, and automatic next-episode playback after a ten-second countdown.

[Source repository](https://github.com/GianCarlozxc/AniQore) (access depends on repository permissions). Source revision: aa824b01781d6255ee0ccf1880fda0fb6c4b07a4.

Known issues: background season metadata may replace richer details; episode metadata can remain stale during a session; rewatch banners and Library completion can remain outdated in some cases.

Settings includes Check for updates. New versions download directly in AniQore and open Android's installer. To publish compatible updates, use a newer numeric version and versionCode, the same signing key, and an uploaded AniQore-vVERSION.apk asset in a published release. Android requires user confirmation and may require Allow from this source.

Metadata and stream availability depend on external providers.
