# AniQore Releases

Android downloads for AniQore.

## Current preview: v1.11.0

[Download AniQore APK](https://github.com/GianCarlozxc/AniQoreRelease/releases/download/v1.11.0/AniQore-v1.11.0.apk) | [Release notes](https://github.com/GianCarlozxc/AniQoreRelease/releases/tag/v1.11.0)

Requires Android 8.0 or newer. This is a debug-signed preview build. App and playback testing are pending manual review.

Features include anime discovery and search, dark/light appearance, Library and Plan to Watch, season/episode browsing, native video controls, completion tracking, resume banners, and automatic next-episode playback after a ten-second countdown.

[Source repository](https://github.com/GianCarlozxc/AniQore) (access depends on repository permissions). Source revision: 766e4a3c228e21d025af8a135fcad9e7dc39c176.

Known issues: background season metadata may replace richer details; episode metadata can remain stale during a session; rewatch banners and Library completion can remain outdated in some cases.

Settings includes Check for updates. New versions download directly in AniQore and open Android's installer. To publish compatible updates, use a newer numeric version and versionCode, the same signing key, and an uploaded AniQore-vVERSION.apk asset in a published release. Android requires user confirmation and may require Allow from this source.

Metadata and stream availability depend on external providers.
